# muxy 0.119.9

## Default keyboard access

Replace the default `-` extra key and its `|` popup with the existing `KEYBOARD` action, displayed as `⌨`:

```text
ESC  /     ⌨    HOME  UP    END    PGUP
TAB  CTRL  ALT  LEFT  DOWN  RIGHT  PGDN
```

The toggle opens or hides the software keyboard independently of terminal mouse reporting and alternate-screen state. Default row and column counts remain unchanged. Existing tap routing and CJK input behavior are unchanged.

User-defined `extra-keys` arrays are not rewritten. If a custom array is present, add `KEYBOARD` to that array to show the button. The dash and pipe popup remain available in custom layouts.

## Upgrade

Install over 0.119.8 without uninstalling and keep the same bootstrap variant. Package `com.termux`, version code 128. Both bootstrap variants and all four ABIs retain the same private signer:

```text
756768af514d3fa0d1c214d54dabd7b0cd088a1723a22f520b90e8e8545262ce
```

Existing muxy-signed addons remain compatible; no addon update is required for this main-app default layout change. Float does not show the main app's extra-key toolbar.

- All ten signed APKs pass checksum, signer, manifest, embedded bootstrap, API 21 imports, and native 16 KiB alignment verification.
- Signed upgrades on API 21 x86 and API 35 x86_64 pass shell execution, rotation/session preservation, and extra-arrow/forward-delete editing.

- The API 35 signed-app suite completes five scenarios without failures, with optional live input skipped. It also checks upstream tap routing and explicit keyboard access across ordinary/alternate screens and mouse modes.
- View lint passes. No physical-device test was performed for this layout change.
