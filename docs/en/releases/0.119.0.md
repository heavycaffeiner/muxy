# muxy 0.119.0

## Changes

- Replace the production Java VT parser with pinned libghostty-vt `0ba6250388641f52135414b38c4259aa682c489b` and recorded muxy compatibility patches.
- Keep the existing app, local PTY transport, terminal view, renderer, settings, extra keys, and session management.
- Add CJK composition, Hangul commit ordering, local preedit deletion, stale-connection rejection, native Unicode layout, and IME cursor anchors.
- Preserve Sixel and iTerm2 inline images, DEC rectangles, terminal queries, colors, selection, and transcript export through native state and existing Java decoders.
- Retain API 21 and all four ABIs. Align the packaged native libraries for 16 KiB pages.
- Fix bootstrap preparation order and assembly dependencies so sequential builds cannot package the other Android variant's bootstrap.

## Downloads and signing

Use `apt-android-7` on Android 7 or newer. Use `apt-android-5` on Android 5 or 6. Choose the device ABI or `universal` if it is unknown. Each variant has `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`, and `universal` APKs.

The package remains `com.termux`. The app label remains Termux. These APKs use a private muxy release key, not the public upstream test key, F-Droid key, or another Termux distributor's key. Android will reject an in-place update from a differently signed installation. Signature-protected Termux add-ons also need a matching signer.

Back up your home directory, packages, and settings before replacing an incompatible installation. Uninstalling removes app data. Do not switch bootstrap variants within an existing installation.

`SHA256SUMS` covers all ten APKs. Verify the downloaded files with:


## Limits of verification

- ARM and ARM64 compile, signature, bootstrap, and ELF checks passed. Their device execution was not tested.
- Samsung Keyboard, live Japanese/Chinese IMEs, custom-font regional fallback, physical keyboards, vim, and tmux were not tested in this release pass.
- A 16 KiB-page device was not used. ELF alignment was checked; this is not a device loading test.
- Native history retention has regression coverage. Comparative legacy/native memory, throughput, and redraw measurements remain open. No equal-or-better performance claim is made.
- Native-backed buffer reads are snapshots. External callers must not treat legacy mutable Java buffer methods or returned rows as the authoritative emulator state.
- App release lint fails on the unchanged `TermuxActivity.onBackPressed` implementation (`MissingSuperCall`) and reports 30 warnings. The release build and tests pass. This lint issue is not suppressed or reported as a passing check.

The universal APK sizes are 122,312,550 bytes for `apt-android-7` and 76,687,206 bytes for `apt-android-5`. No baseline size comparison was made.
