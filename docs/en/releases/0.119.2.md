# muxy 0.119.2

## Fixed

- Keep Hangul composition and committed-jamo replacement ranges intact when a physical Shift key is pressed or released. Adding the double final consonant in `있` no longer loses `ㅆ`.
- Handle Android touchpad two-finger scroll gestures delivered as classified move events, including batched travel and fractional rows.
- Accept wheel events from touchpad sources and unclassified two-pointer touchpad movement.
- Prevent duplicate touch/generic scroll delivery and false remote clicks from buttonless gestures. Preserve primary mouse press/release.
- Keep normal history scrolling, remote mouse-wheel reporting, and alternate-screen arrow-key scrolling.

## Upgrade

Install over muxy 0.119.1 using the same bootstrap variant. Package `com.termux`, version code 121. The release signer is unchanged:

```text
756768af514d3fa0d1c214d54dabd7b0cd088a1723a22f520b90e8e8545262ce
```

Use `apt-android-7` on Android 7 or newer, or `apt-android-5` on Android 5 or 6. Each variant has arm64-v8a, armeabi-v7a, x86, x86_64, and universal APKs. Do not switch bootstrap variants within an existing installation.

- 159 emulator and 46 input/layout/scroll JVM tests passed. Debug build and terminal-view lint passed.

- All ten signed APKs passed signer, embedded bootstrap, API 21 native import, and 16 KiB ELF alignment verification.
- Signed upgrades from 0.119.1 preserved home-directory test data on API 21 and API 35. Shell commands, rotation/session retention, extra-arrow keys, and forward deletion passed on both emulators.

Physical keyboard and touchpad hardware were not attached to the test host. Keyboard checks use the emulator's Linux input device; pointer checks construct Android MotionEvents. OEM event variations remain unverified.
