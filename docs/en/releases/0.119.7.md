# muxy 0.119.7

## Touch gestures

- Single touchscreen tap opens the keyboard without sending a TUI mouse click, including on the alternate screen with mouse reporting enabled.
- Double tap sends one mouse press/release pair at the second tap's position. It does not open the keyboard or run the single-tap URL action.
- Dragging, holding, cancelling, or adding a finger to the second tap does not click.
- Physical mouse, touchpad scrolling, text selection, pinch scaling, and explicit keyboard controls keep their existing paths.

Android's double-tap decision adds a short delay before single-tap keyboard opening. A double tap does not hide an already open keyboard. The terminal protocol does not expose TUI widget focus; gestures select the action explicitly.

## Verification

Shared terminal regressions cover single/double tap isolation, exact PTY click counts, second-release ordering, drag/hold/cancel/multitouch rejection, physical pointers, keyboard access, and existing IME behavior. Exact signed-build and addon verification is recorded with the coordinated distribution. Physical devices and arbitrary TUI application bindings remain outside the verified matrix.
