# muxy 0.119.1

## Fixed

- Support Gboard beta's committed-jamo `replaceText` input. Typing `안` no longer leaves only `ㅇ` in the terminal.
- Preserve legacy Gboard composition, final-consonant carry, Backspace decomposition, and English autocorrection with its trailing spaces.
- Keep the served input connection usable when Android creates and discards another connection during keyboard binding.
- Publish IME selection changes after commits finish, rather than interrupting a word's next syllable.
- Reject stale replacement ranges after submission, terminal navigation, or session reset. Terminal output and scrollback are not editable IME context.

## Upgrade

Install over muxy 0.119.0 using the same bootstrap variant. The package remains `com.termux`; version code is 120. The signing certificate is unchanged:

```text
756768af514d3fa0d1c214d54dabd7b0cd088a1723a22f520b90e8e8545262ce
```

Use `apt-android-7` on Android 7 or newer and `apt-android-5` on Android 5 or 6. Both variants include four ABI APKs and a universal APK. Do not switch bootstrap variants within an existing installation. Other Termux distributions use different signing keys and cannot necessarily be upgraded in place.

## Verification

- 159 emulator JVM tests and 43 composition/layout JVM tests passed.
- API 21 x86 and API 35 x86_64 connection/PTY suites passed. Manually driven tests are skipped unless their input argument is supplied.
- Actual Gboard Korean key taps delivered `안녕 한글 안자 과의` correctly on preload 12.4.05, stable 17.8.7 and 18.4.1, and beta 17.8.4, 18.0.3, and 18.1.3.
- Beta 18.1.3 also passed Backspace decomposition, separator deletion, retyping, and English autocorrection tests.
- All ten signed APKs passed signature, embedded bootstrap, API 21 import, and 16 KiB ELF alignment checks.
- Signed APK upgrades from 0.119.0 preserved home-directory test data on API 21 x86 and API 35 x86_64. Shell commands, session retention across rotation, extra-arrow input, and forward deletion passed on both emulators.
- Actual Gboard beta 18.1.3 input on the signed API 35 APK delivered `안녕 한글` as exactly 13 UTF-8 bytes.

The complete build identifiers and input protocol findings are in [Gboard input compatibility](../gboard-input-compatibility.md). This covers the listed builds and observed protocols, not every Gboard version, physical device, layout, or server-side experiment. Remotly received the same fix.
