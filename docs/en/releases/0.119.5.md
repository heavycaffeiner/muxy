# muxy 0.119.5

## Organization migration

The main repository is now [muxy-terminal/muxy](https://github.com/muxy-terminal/muxy). Existing releases and history are preserved. The six official addon repositories are forked under the same organization.

The app retains package `com.termux`, version code 124, both bootstrap variants, all four ABIs, and the existing private release certificate:

```text
756768af514d3fa0d1c214d54dabd7b0cd088a1723a22f520b90e8e8545262ce
```

Install over 0.119.4 using the same bootstrap variant. Do not uninstall the main app or switch bootstrap variants.

## Shared terminal libraries

The organization addon builds use muxy's terminal libraries instead of the upstream Java terminal implementation. Float uses libghostty-vt and the same CJK input connection, preedit layout, renderer, and key encoder as the main app. Its virtual keys, style reload, and native terminal lifecycle are adapted to those libraries.

API, Tasker, and Widget use muxy's shared library for their existing integration protocols. Styling and Boot do not embed a terminal core. Package names, shared UID, permissions, and the signing certificate are unchanged.

This release does not claim compatibility with every IME, physical device, or TUI. Exact addon verification is recorded with the addon distribution.
